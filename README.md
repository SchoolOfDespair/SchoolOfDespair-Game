# game

in order to open this project, you'll need the [Godot Engine](https://godotengine.org/download/archive/), specifically version 4.7, **with mono support** (at the present moment).  
mono support is required because we created the project with C# originally, then switched to mainly using GDScript.   

some helpful tools that might be useful for development:
- [Material Maker by RodZilla](https://rodzilla.itch.io/material-maker)
